# Spring Redis Playground

A Spring Boot project for exploring Redis integration, caching strategies, and data persistence patterns.

## Technologies

* Java
* Spring Boot
* Redis
* PostgreSQL
* Docker

## Features

* Redis data storage
* CRUD operations
* Database persistence
* Caching examples
* Docker-based local setup

## Getting Started

1. Start Redis and PostgreSQL using Docker.
2. Configure application properties.
3. Run the Spring Boot application.
4. Test the APIs.

## Purpose

This repository serves as a learning playground for understanding how Redis and relational databases can work together in Spring Boot applications.
